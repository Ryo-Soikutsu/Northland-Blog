# Sussy1

## Description

```
what a sussy file
```

## Walkthrough

We're provided with a single text file, with a lot of what appears to be instructions.

<figure><img src="../../.gitbook/assets/image (422).png" alt=""><figcaption></figcaption></figure>

From past experience (see: TISC 2025), I can recognize that this is G-code, which is used in 3D printers to provide instructions on how and when to print layers of a model. To confirm, we can copy one of the instructions, and paste them into a search engine.

<figure><img src="../../.gitbook/assets/image (423).png" alt=""><figcaption><p>Rare moment of Google AI not being dogsh*t</p></figcaption></figure>

We can look for G-code visualizers online, and load the entire instruction set into the simulator to get the simulated 3D output.

<figure><img src="../../.gitbook/assets/image (424).png" alt=""><figcaption></figcaption></figure>

There is a big model in the distance. A bit of spatial manipulation later, and we get the flag
